# METRO CITY — Mobile Web Prototype

A mobile-first 3D open-world city game prototype built with:

- HTML
- CSS
- JavaScript
- Three.js

The game is designed to run directly in a modern mobile web browser.

---

## 🎮 Game Features

### Player

- Third-person player
- Walking
- Running / sprinting
- Jumping
- Player health
- Stamina system
- Smooth camera movement

### 🚗 Vehicle

- Enter and exit car
- Drive around the city
- Gas / acceleration
- Brake
- Reverse
- Steering
- Speedometer
- Vehicle camera

### 🌆 Open World

The prototype includes:

- Roads
- Houses
- Buildings
- Downtown area
- Residential area
- Park
- Trees
- Large playable area
- Different city zones
